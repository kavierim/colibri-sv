# packet
Modules under `src/packet/`.

| Module | Description |
| --- | --- |
| [broadcaster](broadcaster.md) | Duplicate one stream to several outputs. |
| [deinterleaver](deinterleaver.md) | Split one stream into multiple outputs. |
| [header_add](header_add.md) | Prepend a fixed header to each packet. |
| [header_remove](header_remove.md) | Strip a fixed header from each packet. |
| [interleaver](interleaver.md) | Merge multiple packet streams into one. |
| [packet_delay](packet_delay.md) | Delay packets by a fixed number of clocks. |
| [packet_join](packet_join.md) | Concatenate consecutive packets into one. |
