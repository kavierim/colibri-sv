# File I/O

Simulation helpers that read and write binary files. Package `colibri_binaryio` (`binaryio.sv`) is the VHDL package `binaryio`.

### Contents

- `colibri_binaryio` — tasks to write and read a binary file.

### Development status and testing

| Package | Simulation | Self-checking testbench | SVA |
| --- | --- | --- | --- |
| `colibri_binaryio` | yes | `sim/fileio/binaryio_tb.sv` | no |

The testbench uses `sim/fileio/testfile.bin`. That file is generated by the test and is not part of the source tree.
